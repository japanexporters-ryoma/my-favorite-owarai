# お父さんのお笑いシアター 😊✨
**〜 四肢麻痺でベッドに寝たきりのお父様に、毎日の笑顔と元気を届けるYouTube専用アプリ 〜**

介護スタッフやご家族が「探す手間」をゼロにし、ワンタップでお父様が大好きな芸人や有名人（大谷翔平など）の動画を大画面で見せられるWebアプリです。

---

## 🌟 このアプリの特徴と工夫

1. **ワンタップで動画カード一覧表示**
   - 「サンドウィッチマン」「中川家」「かまいたち」「千鳥」「ナイツ」「博多華丸・大吉」「大谷翔平」「吉本新喜劇」「昭和漫才」「落語」などの大きなボタンを用意。
   - 忙しいヘルパーさんや介護スタッフがYouTubeで文字入力して探す手間がなく、ボタンをポンと押すだけで面白い動画カードが瞬時に並びます。

2. **ボタンの自由な追加・カスタマイズ**
   - 「ボタンを追加」から、お父様が好きな芸人や有名人（志村けん、明石家さんま、綾小路きみまろ、大相撲など）を自由に追加・保存できます。

3. **大画面シアターモード ＆ 次の動画への簡単送り**
   - 動画をタップするとすぐに大きな画面でYouTubeが再生されます。
   - 「次の動画」「前の動画」ボタンが大きく配置されており、ワンタップで次のネタへ進めます。

4. **お父さんの「殿堂入り（お気に入り）」保存機能**
   - お父さんが「声を出して笑った」「笑顔になった」動画の「⭐ お気に入り」ボタンを押すと、殿堂入りリストに保存されます。
   - 次に別のヘルパーさんが来られた時も、「殿堂入り動画」タブからすぐにウケる動画を見せてあげられます。

5. **介護・笑顔メモ（スタッフ伝言板）**
   - 「中川家の電車のネタで大笑いした」「午後の体位変換のあとに見せると落ち着く」など、お父様の好みの反応や日々の様子をメモとして残せます。

6. **ベッドから見やすい「文字サイズ調整（特大）」**
   - 画面上部で文字サイズを「小・標準・特大」に切り替え可能。ベッドから少し離れた位置にタブレットやモニターがあってもはっきり見えます。

7. **iPadやスマホからでもそのまま使える**
   - このPCと同じWi-Fiに繋がっているiPadやスマートフォンから、案内されたアドレス（例: `http://192.168.x.x:3001`）を開くだけでそのまま操作・視聴できます。

---

## 🚀 使い方

### 1. かんたん起動（Windows）
フォルダ内にある **`起動する.bat`** をダブルクリックするだけです。
自動的にブラウザが立ち上がり、アプリ画面が開きます。

### 2. 手動で起動する場合
```bash
# 依存パッケージのインストール（初回のみ）
npm install

# アプリの起動
npm start
```
起動後、ブラウザで `http://localhost:3001` を開いてください。

---

## 💻 動作環境
- Windows / macOS / Linux
- Node.js v18 以上
- 各種ブラウザ（Google Chrome, Safari, Microsoft Edge 等）
